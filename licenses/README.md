# Licensing status

The original `two` and `two dft` directories did not include a project LICENSE. The MIT label in the supplied screenshot belongs to the example project and does not apply to this package. The root LICENSE records the current status and grants no new usage or redistribution rights.

Before public distribution, the authors need to confirm the redistribution terms for their own code, C2DB data, third-party libraries, and Materials Studio/CASTEP project contents. This organization did not add commercial software installers or pseudopotentials, and it did not change existing notices in the source files.
